# Jason Loh Property Website — V1

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `css/style.css`, `js/main.js`, `js/projects.js`.
3. In GitHub: Settings → Pages → Deploy from branch → main → /(root).
4. Open the generated GitHub Pages URL.

## Before publishing
- Change `WHATSAPP_NUMBER` in `js/main.js`.
- Replace project images with your own approved project images.
- Fill in confirmed price / tenure / built-up / land-size data in `js/projects.js`.
- Add your real contact details and social links.
- Verify all project information with the relevant developer / official source.
